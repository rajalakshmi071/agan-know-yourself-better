# Agan – Know Yourself Better ✨

**Agan** is a personal self-reflection web application designed to help users understand their thoughts, manage overthinking, and make clearer decisions.

Meet **Mirage**, a friendly pixel-cat companion that interacts with users, responds to their messages, and offers gentle guidance through an engaging interface.

## 🌟 Features

- **Mirage – Personal Companion:** Chat with Mirage and receive supportive, context-based responses.
- **Decision Helper:** Enter a dilemma and compare two choices to receive a suggested direction.
- **Confidential Profile:** Explore a self-clarity score and personal reflection indicators.
- **Consent Control:** Choose whether to allow conversation-based personalization.
- **Interactive UI:** Enjoy a dark-themed interface with golden accents, animations, and a pixel-cat companion.
- **Motivational Reminders:** Receive small reminders during your experience.

## 🛠️ Technologies Used

- HTML5 – Application structure
- CSS3 – Styling, animations, and responsive layout
- JavaScript – Interactive features and application logic
